# Benchmark and protocol investigation — 26 October 2026

Researcher track of the requested Feynman deep-research/literature-review workflow. This is a fresh primary-source investigation. Existing project experiments have not been rerun; none of the benchmark results below are our results. Sources and reading boundaries are in `benchmarks-sources.json`. The analysis deliberately does not take the earlier three-feature gate as the answer.

## Main findings

1. A benchmark name does not specify a TTA task. Resetting, order, class composition, batch size, access to future samples, and whether adaptation occurs before a scored prediction can change the comparison. TTAB directly demonstrates sensitivity to tuning and source-model properties. [Zhao2023Pitfalls](https://proceedings.mlr.press/v202/zhao23d.html).
2. The literature already includes systematic domain/class stream variation: UniTTA defines 36 combinations and evaluates 24 meaningful settings in the inspected paper. Its method also estimates domain-specific, class-balanced normalization and exploits temporal features. Neither factoring classes from domains nor testing mixed/imbalanced streams alone is a new contribution. The released sampler is explicitly described as modified, so exact version pinning matters. [Du2024UniTTA §§3–5, Appendix B](https://arxiv.org/html/2407.20080v1), [author repository](https://github.com/LeapLabTHU/UniTTA).
3. The current CLIP benchmark TTABC distinguishes parameter, external-state, and inference updates. It finds shift-dependent paradigm preferences and explicitly names dynamic selection as future work, but that statement must be checked against independent whole-method selectors before becoming our novelty claim. Its coverage is CLIP image classification. [Huang2026TTABC §§2–5 and Appendix B](https://arxiv.org/html/2606.14299v3).
4. **A new online-updating WILDS protocol must be distinguished from the official submission rules.** Standard submissions forbid test-set training/model selection and evaluation batch statistics; non-standard submissions retain the test-training/model-selection ban. The official leaderboard nevertheless contains historical ARM-BN and Test-time BN adaptation baseline rows. Those rows are not evidence that new test-trained submissions are permitted, while the rules should not be generalized into a blanket claim about every inference-only adaptation mechanism. WILDS 2.0 supplies designated unlabeled splits for pre-test adaptation, a separate access regime. [Official submission rules](https://wilds.stanford.edu/submit/), [historical baseline rows](https://wilds.stanford.edu/leaderboard/), [Sagawa2021WILDSUnlabeled](https://arxiv.org/abs/2112.05090).
5. There are live TTA benchmark tools and a living leaderboard. It would be inaccurate to say none exist. Their results remain conditional on the chosen task/model/protocol, and the inspected living leaderboard's reproduction-code link is still marked TBD. [Living leaderboard](https://test-time.cc/tta-leaderboard/), [TTAB repository](https://github.com/lins-lab/ttab), [ROID/RMT repository](https://github.com/mariodoebler/test-time-adaptation).

## Dataset and task matrix

| Benchmark | What it actually tests | Appropriate metric | Use in this project; limitation |
| --- | --- | --- | --- |
| CIFAR-10-C / CIFAR-100-C | Small-image classification under algorithmic corruptions; common protocol uses 15 corruptions × 5 severities. | Mean error across explicitly declared corruptions/severities; per-family/worst-family error. | Cheap screening and action-headroom work. A held-out severity is weaker than an unseen corruption family. Preserve original-image separation across router development and evaluation. |
| ImageNet-C | ImageNet validation images transformed by common corruptions. | Raw mean corruption error or accuracy; original mCE is an AlexNet-normalized metric and must be distinguished from raw mean error. | Core large-scale corruption test. Different checkpoints, crops, severe-only versus all-severity averaging, or adaptation states make published numbers incomparable. |
| ImageNet-3DCC | Twelve corruptions, many using estimated scene geometry, including depth-dependent focus/lighting/motion effects. | Declare included transformations and severities; raw classification error is interpretable. | Transfer beyond 2D corruption families. It is not independent at the underlying-image level if development uses other versions of the same ImageNet image. Estimated depth and synthetic transformations remain approximations. |
| ImageNet-V2 | Resampled test images created to resemble ImageNet's original collection procedure. | Top-1 accuracy/error, exact V2 subset identified. | Natural sampling shift; no explicit physical-cause annotation. A held-out domain name does not provide the router a causal label. |
| ImageNet-A | Naturally occurring, adversarially filtered images of a subset of ImageNet classes. | Top-1 accuracy using the declared class mapping. | Severe natural recognition failure. Distinguish it from ImageNet-O, which is an unknown-class detection task. |
| ImageNet-R | Renditions in a subset of ImageNet classes. | Top-1 accuracy with the subset/mapping fixed. | Style/representation shift rather than camera corruption. Source models trained on different data can have very different headroom. |
| ImageNet-Sketch | Sketch-like images matched to ImageNet categories. | Top-1 accuracy/error. | Larger shape/style change. A normalization-only intervention may lack the capacity needed to help. |
| DomainNet (full cleaned) | Six domains, approximately 0.6M images, 345 classes; originally a multi-source UDA dataset. | Average accuracy across declared source→target transfers, plus per-domain/class results. | Specify whether source training uses one domain or several, whether source examples are retained, and whether target adaptation is full-domain or streaming. Use the author site's cleaned split lists. |
| DomainNet-126 | Common reduced four-domain/126-class subset used in TTA studies. | Average and per-domain accuracy with exact split/model disclosed. | Results are not full-DomainNet results. The chosen real/clipart/painting/sketch protocol must be pinned to a concrete implementation. |
| WILDS iWildCam | Species recognition across camera traps, with natural background/illumination/animal-frequency differences. | Official OOD macro F1; average accuracy is secondary. | Relevant real deployment case. Stream order and access are a new research protocol if adding online TTA. Do not substitute accuracy for the official macro F1. |
| WILDS FMoW | Satellite land-use classification with time and region shifts. | Official worst-region accuracy, with average accuracy secondary. | Tests whether adaptation helps poor regions rather than only the dominant group. Respect time ordering and distinct unlabeled-development/test access. |
| WILDS Camelyon17 | Binary tissue-patch classification across hospitals. | Official OOD average accuracy; hospital/slide breakdown useful. | Strong seed variability and correlated patches require patient/slide-level resampling, not treating every patch as independent. Official guidelines request 10 seeds for submission. |
| ACDC | Real adverse-weather/time driving scenes with fine segmentation annotations, normal-condition correspondences, and invalid-region masks. | Standard semantic segmentation mIoU; use uncertainty-aware metrics only when evaluating that separate task. | Optional dense-prediction extension after classification succeeds. Original dataset has 4,006 adverse images; later extension adds panoptic and normal-image annotations. Pin which version and task. |
| Cityscapes-C | Algorithmic corruption of Cityscapes-style segmentation data; exact construction varies by toolkit. | mIoU with corruption/severity aggregation stated. | Controlled segmentation transfer, not interchangeable with real ACDC. A paper claiming a new general router should eventually include another task, but this is not needed for the first falsification pilot. |

## Which directions improve these tasks, and what limits them?

The limitations column combines observed failures explicitly documented by the cited benchmarks with mechanistic implications. It is not a claim that every instance of a direction has exactly the same defect.

| Direction | Where evidence favors it | Main remaining hindrance and consequential comparison |
| --- | --- | --- |
| Strong frozen source models, robustness augmentation, pretraining | Stronger corruption and some natural-shift performance before adaptation. Schneider demonstrates complementary gains from BN-statistics replacement on multiple source models. | Source quality changes adaptation headroom; a weak source can make a new adapter look more valuable. Include strong frozen and robust-pretrained sources. TTAB finds augmentation/pretraining features can affect adaptivity in ways source accuracy alone does not explain. |
| Updating normalization statistics | Cheap, large gains possible on common corruptions. | Mixed domains, small/correlated batches, and class-mixture change can contaminate the moments. Compare ordinary BN, robust BN, TTN, balanced/domain-conditioned BN, and source interpolation where applicable. Class balancing is already addressed by TRIBE/UniTTA. |
| Entropy minimization and reliability filtering | Effective on common corruptions when the proxy aligns with true correctness; Tent/ETA/EATA/SAR are standard controls. | Low entropy can also reflect confident mistakes. Gradients may reinforce collapse; thresholds depend on shift and source model. Fewer backward passes do not by themselves establish a superior latency tradeoff. |
| Teacher/student, restoration, replay, and ensembling | CoTTA/RMT/RoTTA/ROID target changing, noisy, correlated streams. | Error propagation, stale memory, forgetting, and teacher costs remain. Long streams reveal failures that short concatenations miss; include RDumb and source-return evaluation. Source replay and source-free variants must be separated. |
| Resetting and selective state retention | RDumb can outperform more complex continual methods on CCC; later reset methods refine where/when. | Resetting throws away useful adaptation while retaining state risks contamination. A one-step router trained from the source state does not automatically solve this sequential tradeoff. This last statement is an inference requiring direct method checks. |
| Domain-aware experts / normalization components | Helpful under heterogeneous/mixed domain streams; UniTTA routes statistics to inferred domains. | Estimated domains may reflect semantic class composition; number of components, memory, unseen mixtures, and expansion errors matter. Domain labels cannot be secretly supplied at inference. |
| CLIP prompts/adapters/prototype updates | TTABC finds lightweight prototype mechanisms strong for natural shifts and norm-layer adaptation helpful on corruptions within its inspected setup. | Heavy optimization has diminishing returns and high cost; update choice depends on shift. Known label names and CLIP pretraining constitute extra assumptions compared with a conventional source classifier. |
| CLIP external-state / inference refinement | Competitive accuracy/cost tradeoffs without extensive parameter optimization; some mechanisms use augmentations or caches. | Caches can accumulate wrong pseudo-labels; batch class coverage and ordering assumptions can be favorable. StatA directly tests variable effective classes and non-i.i.d. batches. Strong zero-shot priors make SOURCE an essential baseline. |
| Source-free full-domain adaptation | DomainNet/Office-Home methods can exploit target clusters and multiple passes. | Future-target access and repeated passes exceed strict online access; clustering can fail if geometry/label-set assumptions break. Do not compare these numbers directly to single-pass causal TTA. |
| Unsupervised validation and whole-method selection | Motivation is strong because benchmark rankings vary. | Selection proxies, auxiliary supervision, target-label tuning, and state-dependent counterfactuals are the bottlenecks. The benchmark's oracle-best action is an upper bound, not a deployable method. New algorithm claims need direct whole-method selector comparisons. |

Useful evidence anchors: [Schneider2020CovariateAdaptation](https://papers.nips.cc/paper_files/paper/2020/hash/85690f81aadc1749175c187784afc9ee-Abstract.html), [Zhao2023Pitfalls](https://proceedings.mlr.press/v202/zhao23d.html), [Press2023RDumb](https://proceedings.neurips.cc/paper_files/paper/2023/hash/7d640f377893fc5f22b5610e175ef7c3-Abstract-Conference.html), [Du2024UniTTA](https://arxiv.org/html/2407.20080v1), [Zanella2025StatA](https://openaccess.thecvf.com/content/CVPR2025/html/Zanella_Realistic_Test-Time_Adaptation_of_Vision-Language_Models_CVPR_2025_paper.html), [Huang2026TTABC](https://arxiv.org/html/2606.14299v3).

## Benchmarking directions already taken

- **TTAB:** explicit selection difficulty, model dependence, corruption/correlation/label shifts. Its publisher abstract says nine algorithms; linked PDF and repository describe ten. Record the discrepancy rather than treating a count as a substantive result.
- **Benchmark-TTA:** unifies 13 methods/variants on CIFAR-10-C, CIFAR-100-C, ImageNet-C, DomainNet and Office-Home, spanning online/offline and instance/batch/domain adaptation. Useful implementation source; scope does not establish 2026 SOTA. [Yu2023BenchmarkTTA](https://arxiv.org/abs/2307.03133).
- **ROID/RMT codebase:** supports reset-each-shift, continual, gradual, mixed domains, correlated and combined protocols, including conventional and CLIP models. Pin a commit and check method-specific preparation requirements. [Author code](https://github.com/mariodoebler/test-time-adaptation).
- **CCC/RDumb:** long, controlled, smoothly changing compounded corruptions reveal collapse hidden by short concatenations. Exact-length/source-ID reuse should be recorded; a longer stream is not automatically more statistically independent. [Press2023RDumb](https://domainadaptation.org/continual/).
- **UniTTA:** independently varies domain and class correlation/imbalance. Distinguish the 36 formal combinations from 24 evaluated realistic settings. [Du2024UniTTA](https://arxiv.org/html/2407.20080v1).
- **Time-constrained evaluation:** Alfarra et al. already reduce adaptation opportunities for slower methods on constant-rate streams. A fast simple method can beat a slower method under this protocol. [Alfarra2024TimeConstraints](https://proceedings.mlr.press/v235/alfarra24a.html).
- **Tempora:** discrete, continuous, and amortized utility capture different deadline/budget assumptions. The paper reports ranking changes across shifts and time pressure, so a claim of computational efficiency must specify the deployment objective. [Sreeram2026Tempora](https://proceedings.mlr.press/v306/sreeram26a.html).
- **BoTTA:** periodic adaptation; limited samples, incomplete class exposure, diverse and compounded shifts; evaluates resource consumption on Raspberry Pi 4B and Jetson Orin Nano. Its periodic held-out evaluation is distinct from adapting/evaluating on the same batch. Publisher fulltext surfaced in search; DOI retrieval subsequently returned 403, so quantitative tables were not audited in this refresh. [Danilowski2026BoTTA](https://doi.org/10.1145/3774906.3800498).
- **TTABC and StatA:** CLIP paradigm mechanisms, natural versus corruption shifts, class coverage and correlated streams. Transferring conclusions to other architectures requires evidence.
- **Recovery-complexity theory:** the 2026 ICML paper explicitly studies adaptation recovery time and information limits under nonstationarity. It precludes claiming that recovery time is a newly introduced concept. Only abstract/metadata were checked here; actual bounds/assumptions need full reading before using its theorem. [Zhou2026RecoveryComplexity](https://proceedings.mlr.press/v306/zhou26be.html).

## A fair empirical decision sequence for a clean-slate prospect

1. **Fix the claim and access regime first.** Conventional source classifier and CLIP are different tracks. Choose one for the first experiment. Declare auxiliary labeled development data, source-statistics retention, class names, domain boundaries, and all target data access.
2. **Establish complementary interventions.** On disjoint support/query identities, quantify whether any fixed method dominates a compact action menu. Use oracle ranking only to measure headroom. If no meaningful crossing survives finite-query uncertainty, a policy selector is unnecessary.
3. **Separate current shift from current adaptive state.** Repeat identical input conditions from source, correctly adapted, and contaminated states, using matched optimizer/teacher/buffer snapshots for each counterfactual. Ask whether input-only routing fails because action value depends on earlier updates. This is a candidate experiment, not an already verified novelty gap.
4. **Test extrapolation at several levels.** New image identities; unseen corruption families; unseen compositions; changed correlation/prior; new source checkpoint; one natural-shift dataset. Sharing clean identities across family splits compromises the interpretation of generalization.
5. **Score deployment consequences.** Mean and worst-group accuracy; harmful-update rate relative to SOURCE; post-transition recovery; source-return behavior; selection regret; throughput/latency/memory; utility under declared deadline/budget. Charge routing, candidate probes, state copies, resets, teachers, and augmentation passes.
6. **Use demanding controls.** Strong frozen source, best development-selected fixed action, dynamic nearest baselines, random/matched-frequency switching, periodic reset, compute-matched inference/augmentation, and a state-agnostic version. Label-free inference does not excuse hidden target-label model selection.

The most useful question from this benchmark audit is not merely whether policies rank differently by named corruption. It is whether deployable, unlabeled evidence predicts **intervention benefit from the actual current state** under a new joint shift/stream regime, when strong source and fixed-policy baselines and total costs are controlled. Direct predecessor checks are still required; this audit does not certify an open gap.
